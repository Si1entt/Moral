**角色：** 你是道德心理学和自然语言处理数据生成领域的专家。

**任务：** 基于**道德基础理论 (MFT)** 和指定的**目标词汇**，生成一个“道德最小对”数据集。

**输入：** 一个目标词列表，其中每一项包含：

1. `词语`：需包含的具体道德词汇。
2.  `类别`：MFT 类别（例如：`care.virtue` [关爱.美德], `fairness.vice` [公平.恶德]）。

**要求：**

1.  **关键词约束（强制）：**

      * 如果 `类别` 是 **美德 (Virtue)**，该 `word` **必须**原样出现在 `virtue_suffix`（美德后缀）中。
      * 如果 `类别` 是 **恶德 (Vice)**，该 `word` **必须**原样出现在 `vice_suffix`（恶德后缀）中。

2.  **对称性约束（对控制变量至关重要）：**

      * `Vice_Suffix`（恶德后缀）和 `Virtue_Suffix`（美德后缀）必须在**结构和形式上相似**。
      * **长度：** 它们的字数/词数应大致相同。
      * **句法：** 使用相似的句式（例如，如果一个使用“我 [动词] [对象] 以 [结果]”，另一个也应遵循相同的模式）。
      * **主题：** 保持核心动作/话题尽可能一致；仅改变“道德方向”（极性）。
      * 理想情况下，它们应作为\*\*最小对（Minimal Pairs）\*\*发挥作用，即仅改变道德形容词/动词。

3.  **语境连贯性：**

      * `Context`（语境）：一个中立的设定（1句话）。
      * 两个后缀都必须是该 `Context` 在语法上自然的延续。

4.  **输出格式：** JSON。

**示例：**
输入：`{"词语": "“同情", "类别": "care.virtue"}`

输出：
{
  "target_word": "同情",
  "category": "care.virtue",
  "pairs": [
    {
      "context": "当那个无家可归的人请求一些零钱时,",
      "virtue_suffix": "我表现出了同情并给了他一些钱。",
      "vice_suffix":   "我表现出冷漠并冷冷地看了他一眼。"
    }
  ]
}
（注：两个后缀都遵循“我表现出 [属性] 并 [动作]”的结构，保持了结构对称性。你可以选择其他类型的句式。）

请为以下词表生成配对：
[
  {"词语": "{word}", "类别": "{category}"}
]
